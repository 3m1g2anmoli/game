# 星际收集者

这是一个网页小游戏：玩家操控飞船接住能量金币、躲避陨石，尽可能获得更高分数。游戏会随着分数增加逐渐加快，最高分会保存在浏览器本地。

## 怎么打开

直接双击 `index.html`，或在浏览器中打开它即可游玩。电脑使用左右方向键，手机使用页面下方的左右按钮；按 `P` 可以暂停，按空格可以开始。

## 开发说明

本项目由 CodeX 协助开发完成。开发过程分为：先确定接金币与躲障碍的核心玩法，再制作 Canvas 游戏循环、碰撞检测、计分和生命值系统，最后补充响应式布局、触控操作、最高分保存和视觉样式。

## 分支结构

- `main`：正式版
- `develop`：开发版
- `feature/*`：独立功能分支
